### `9a64375` feat(anubhav): deanery-parish map API, nav fixes, chaperone shape + UX polish

Committed all prior-session staged work plus new additions:

#### `src/api/anubhavMock.js` + `src/api/anubhavApi.js`
- Added `MOCK_DEANERY_PARISH_MAP` (16 deaneries / 154 parishes, matching backend static source of truth).
- Added `mockGetDeaneryParishMap()` — returns the diocese-wide `deanery → [parishes]` map.
- Added `getDeaneryParishMap()` API facade in `anubhavApi.js`; routes to mock or `GET /anubhav/deanery-parish-map`.
- Added `ROUTES.deaneryParishMap` constant.

#### `src/pages/RegisterYouth.jsx`
- Now loads deanery list from `getDeaneryParishMap()` on mount instead of the static `deaneriesForPlace(activePlace)` helper. Deaneries and parishes are now driven by the live diocese map.

- Chaperone list now reads `safeArray(response.data?.chaperones)` (correct envelope) instead of `safeArray(response.data)`.
- `createChaperone` success: reads `response.data?.chaperone?.id` to auto-select the new chaperone.
- Deanery and Parish dropdowns now show `"— Select Deanery —"` / `"— Select Parish —"` placeholder (disabled) instead of "All X".
- Added inline `<Alert severity="info">` guidance when no deanery or no parish is selected yet.
- Added inline alert when parish is selected but no eligible youth are found.

#### `src/components/Dashboard.jsx`
- `profile_holder` users who have `event_role === 'loc'` or `'dexco'` now get the full event manager nav (previously they fell into the profile_holder branch and only saw MyEvent).
